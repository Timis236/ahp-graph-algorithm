# Overview
A graph-searching algorithm created for use during research on AHPs (Alternating Hamiltonian Paths). In general, the code searches for all possible AHPs in all fully-connected 2-color graphs of size N, and outputs the results in the console and/or a file. Graphs are encoded as a matrix structure - the element on row m, column n represents the edge between node m and node n, and its value (1 or 0) dictates the color of that edge. Then, the code uses algorithms to find any/all AHPs that are possible on that graph, and outputs them as a sequence of numbers (the node numbers that must be sequentially followed in order to reach every node by crossing alternating color edges). The primary focus of the code is efficiency, so as to deal with as large of an N as possible. As such, many tricks/techniques were used to reduce run-time as much as possible, such as multi-threading, bit operations, and other time-saving shortcuts.

The definitions at the beginning of the code define various aspects of how the algorithm will run, and can be adjusted accordingly. Lots of documentation is present within the code to give a more detailed explanation on certain aspects.
